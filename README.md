## 💎 Design System: "Midnight & Cyan"
The UI utilizes a **Vertical Content Flow** and a custom-built midnight theme designed for high-end tech environments:
* **Background:** Midnight Ink (`#050810`)
* **Accents:** Electric Cyan (`#00f2ff`)
* **Styling:** Glassmorphism with neon border-glow effects and smooth transitions.



---

## 🛠️ Key Features & Functional Logic

### 🔔 Smart Notification System
* **Live Feedback:** Features a glowing "Pulse Dot" for unread alerts.
* **Interaction:** Clicking the bell toggles a sliding notification panel and programmatically clears the unread status via JavaScript.

### 👤 User Management & Security
* **Identity:** Branded for **Collins Chele** with a "Lead Developer" designation.
* **UX:** A functional, animated dropdown menu for account settings, security, and logout.

### 📊 Advanced Data Visualization
* **Chart Engine:** Powered by **Chart.js** featuring:
    * Smooth Bezier curves for data continuity.
    * Custom linear gradients for a "glowing" aesthetic.
    * Responsive resizing for mobile, tablet, and desktop views.
